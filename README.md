# Employees table

Interactive employees table in vanilla JavaScript – the final project of the JS Advanced module.

**[▶ Live demo](https://natakovbasniuk.github.io/js_employees_table_DOM/)**

## What I implemented
- Sorting by any column in both directions (click on the header)
- Row selection
- A form generated with JavaScript for adding new employees
- Form validation with success and error notifications
- Inline editing of a cell on double click (save on Enter or blur)

## Tech stack
JavaScript (ES6+), DOM, events, HTML5, CSS3

## Run locally
```bash
npm install
npm start
```
